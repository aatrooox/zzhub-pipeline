# tips-3-4 模板规范

比例：`3:4` | 尺寸：900×1200 | 用途：小红书风格结构化要点卡

## 适用场景

- 用户说"N 个方法 / 技巧 / 步骤 / 要点"
- 用户说"小红书要点卡 / 干货清单"
- 内容为 3–5 条有标题（可选副标明）的并列技巧

## 渲染命令

```bash
bun ./scripts/render-card.ts \
  --template tips-3-4 \
  --text "写作变现的\n5 个核心技巧" \
  --tip "选题精准::锁定高搜索量、低竞争度的细分话题" \
  --tip "钩子开头::前 50 字决定是否被划走" \
  --tip "结构清晰::小标题 + 短段落，移动端必须" \
  --tip "引导互动::结尾提问或给出可执行行动" \
  --tip "持续复盘::每月看数据，找爆文规律" \
  --highlight "#22a854" \
  --bg "#e6f5ef" \
  --footer "公众号 · 早早集市" \
  --out tmp/tips-card.png
```

如果 tip 只有标题，不带副标明，省略 `::` 后半部分：

```bash
  --tip "选题精准" \
  --tip "钩子开头" \
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--template` | `tips-3-4` | 模板名称 |
| `--out` | — | 必填，输出 PNG 路径 |
| `--text` | 空 | **必填**。标题文案，支持 `\n` 手动换行，pretext 自适应字号 |
| `--tip` | — | 可重复传入，每条格式 `标题::描述`，描述可省略 |
| `--hl1/hl2/hl3` | 关闭 | 整行高亮（作用于 `--text` 对应行） |
| `--highlight` | `#22a854` | 强调色，用于序号圆圈、badge 边框、高亮文字 |
| `--bg` | `#e6f5ef` | 背景色 |
| `--footer` | `公众号 · 早早集市` | 底部水印文字 |
| `--icon` | 默认 logo | 左上角圆形 icon |

## 内容建议

| 位置 | 建议 |
|------|------|
| 标题 (`--text`) | 10–20 字，含数字最佳，如"5 个核心技巧" |
| tips 条数 | 3–5 条；超过 5 条会压缩间距，视觉密度过高 |
| 每条标题 | 4–10 字 |
| 每条描述 | 10–25 字，超长会换行，撑高 tip 区域 |

标题由 pretext 引擎根据可用空间自动选择最大可用字号，tip 区域高度固定，两者之间通过两步测量动态分配空间。

## 默认 icon

默认使用 `assets/icons/zzclub-logo-black.jpg`。文案含 "openclaw" 或 "skill" 关键词时自动切换为 OpenClaw logo。

## 使用规则

- 内容是「N 个 XX」列表型干货 → 用本模板
- 内容是金句 / 单标题封面 → 用 `poster-3-4`
- 内容是公众号文章封面图 → 用 `wechat-cover-split`
- **强规则：tips 条数不足 3 条时，改用 `poster-3-4` 做多行标题更合适**
